# Project Charter Template

## Purpose
To formally establish the project and authorize its initiation.

## Sections
- Project title
- Purpose
- Objectives
- Scope
- Stakeholders
- Deliverables
- Timeline
- Budget estimate
- Risks
- Governance structure

## Sample Summary
Project Title: Integrated Citizen Service Delivery Platform
Department: Department of Urban Development
Project Sponsor: Principal Secretary
Project Manager: Senior Consultant
Budget: INR 3.4 crore
Timeline: 14 months

## Key Points
The project aims to create a digital experience for citizen service requests, integrate department workflows, and reduce manual effort through a unified platform.

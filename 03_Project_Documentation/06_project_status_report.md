# Project Status Report Template

## Purpose
To provide a concise status update to stakeholders.

## Sample structure
1. executive summary
2. schedule status
3. budget status
4. risk and issue summary
5. key deliverables
6. decisions required
7. next steps

## Example summary
The project is on schedule for the current phase, with 72% of planned activities completed. Budget utilisation is within the approved range. The main risk is data migration readiness and vendor coordination.

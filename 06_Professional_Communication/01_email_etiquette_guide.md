# Professional Email Etiquette Guide

## Purpose
To create clear and respectful written communication.

## Good Structure
- Subject line with clarity
- Greeting
- Purpose statement
- Key points
- Action needed
- Polite close

## Example
**Subject:** Request for review of draft DPR for Integrated Citizen Service Delivery Platform

Dear Sir,

Please find attached the draft Detailed Project Report for review and guidance. The report includes project need, scope, implementation plan, financial estimate, and risk assessment.

Your suggestions on governance arrangements and financial phasing would be valuable before submission to the competent authority.

Kind regards,
[Name]

# AI Workflow and Prompt Library

## Responsible AI use
AI should accelerate the work but never replace facts, judgement, or official review.

## Prompt examples
- Draft a concept note for a digital citizen service platform for a fictional Odisha government department.
- Summarise this DPR in a six-slide executive deck.
- Rephrase this email in a formal government communication style.
- Convert this project update into a concise status note for senior officers.

## Best practice workflow
1. Draft with AI
2. Review structure and logic
3. Check facts and numbers
4. Rewrite in official tone
5. Final human approval

# Concept Note Template

## Purpose
To present the rationale, objective, and relevance of a project to decision-makers.

## Structure
- Background
- Problem Statement
- Objectives
- Scope
- Proposed Approach
- Expected Outcomes
- Budget Summary
- Risk Overview

## Sample
A fictional project concept note for a citizen service portal in Odisha.

### Background
The department serves a large number of citizen requests on a daily basis, many of which are manually processed.

### Objective
To digitise and streamline service delivery and improve monitoring control.

# 12-Week Learning Roadmap

| Week | Focus | Core Outputs |
|---|---|---|
| 1 | Professional documentation fundamentals | notes, memos, template pack |
| 2 | Government correspondence | letters, orders, reminders, MoM |
| 3 | Project docs I | concept note, charter, proposal |
| 4 | Project docs II | DPR, BRD, SRS, progress report |
| 5 | Procurement I | EOI, RFQ, RFP, SoW, ToR |
| 6 | Procurement II | evaluation, SLA, MoU, bid report |
| 7 | Presentation design | executive decks and dashboards |
| 8 | Communication & English | email, speeches, scripts |
| 9 | Meeting management | agendas, MoM, ATR, actions |
| 10 | Excel & dashboards | KPI dashboards and trackers |
| 11 | AI tools | smart prompt workflows |
| 12 | Capstone project | full consultancy portfolio |

## Daily practice model
- 10 minutes: English and vocabulary
- 10 minutes: document drafting
- 5 minutes: slide practice
- 5 minutes: stakeholder communication drill

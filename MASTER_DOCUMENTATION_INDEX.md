# Master Documentation Index

## Core learning structure
This course includes a complete set of ready-to-use training materials covering professional documentation, official correspondence, project documentation, procurement, executive presentation, communication, meetings, reporting, AI tools, and a realistic Odisha SeMT simulation.

## Study flow
1. Start with fundamentals and writing quality.
2. Practise official correspondence and drafting.
3. Build project documentation and procurement files.
4. Create executive decks and reporting dashboards.
5. Finalise the project simulation and capstone.

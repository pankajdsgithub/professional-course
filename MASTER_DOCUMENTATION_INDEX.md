# Master Documentation Index

## Course purpose
This index helps the learner quickly find the correct document type, project artifact, training resource, or assignment relevant to each stage of the programme.

## Learning approach
The course is built around a single fictional government digital project used consistently across documents, presentations, correspondence, and reports. This continuity is important because it reflects how real consulting work actually develops across a project lifecycle.

## Recommended document flow for real project work
1. project note / meeting note
2. concept note and approval request
3. project charter and project plan
4. BRD / SRS / FRD
5. DPR and financial estimate
6. RFP / ToR / SoW
7. technical and financial evaluation
8. implementation monitoring and status reports
9. UAT report and closure report

## Deliverable categories
- Official government communication
- Project and programme documentation
- Procurement and contract support documents
- Executive communication and presentation products
- Monitoring, KPI, and project control reports
- Capstone-quality consulting submissions

## Final training objective
The learner must be able to create documents and communication that are professional, objective, concise, and suitable for senior government review without needing hand-holding from a supervisor.

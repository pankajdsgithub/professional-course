# Learning Path Guide

## Recommended study sequence
1. Start with Module 1 and 2 for documentation and writing fundamentals.
2. Move to Modules 3 and 4 for project and procurement work.
3. Practice Module 5 for presentation design.
4. Improve speaking and meeting capability through Modules 6 and 7.
5. Use Modules 8 and 9 for dashboards, reporting, and productivity tools.
6. Complete the Odisha simulation and final capstone.

## Daily practice rule
Write one formal document or update every day, then review it for tone, structure, and clarity.
